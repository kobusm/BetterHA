## Description (4000 characters max)

```
BetterHA is a fast, native iOS companion for self-hosted and cloud Home Assistant installations. It's a lightweight alternative to the stock companion app, built for anyone who manages more than one Home Assistant instance — home, a vacation property, a family member's house, or a work site.

FOUR INSTANCES, ONE APP
Configure up to four separate tabs, each pointing at its own Home Assistant instance. Give each a name, a local address, and an optional remote address, then switch between them instantly — no re-login required.

SMART CONNECTION HANDLING
BetterHA tries your local address first for the fastest possible connection, and automatically falls back to your remote address if you're away from home. If neither can be reached, you'll see a clear "Can't connect" screen with a Retry button instead of a blank page.

YOUR HOME ASSISTANT FRONTEND, AS-IS
BetterHA loads your existing Home Assistant web interface exactly as it is — dashboards, sidebar, and all — so there's nothing new to learn and nothing missing. Sign in once and stay signed in, just like Safari.

BUILT FOR IPHONE AND IPAD
A clean five-tab layout (four instances plus Settings) that remembers the tab you last used, with pull-to-refresh support and native performance throughout.

BetterHA is an independent app and is not affiliated with, endorsed by, or sponsored by Home Assistant or Nabu Casa.
```

## Notes

- "Home Assistant" appears only descriptively (this app is a client for it),
  with an explicit non-affiliation disclaimer in the description — keeps
  trademark risk low. Don't use the Home Assistant name or logo in the App
  Store screenshots/icon.
- Subtitle (30 chars max, separate field) suggestion: `Multi-home HA client`
  (21 characters).
- Category suggestion: Utilities or Lifestyle (Home Assistant's own app
  lists under Utilities).
- Age rating: 4+ (no objectionable content) is standard for this kind of app.
- You'll also need: support URL, privacy policy URL (required even for an
  app with no analytics/tracking — state plainly that BetterHA collects no
  user data and all traffic goes directly to the user's own HA instance),
  and screenshots for each supported device size.
